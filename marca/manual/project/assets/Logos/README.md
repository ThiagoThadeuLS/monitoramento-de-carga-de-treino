# Logos

Todos em SVG, desenhados numa grade de 64 (veja Logo no README). Use sempre os arquivos; nunca redesenhe a palavra com uma fonte.

- **carga-horizontal-escuro / claro**: padrão em fundo noite / fundo claro.
- **carga-horizontal-branco / preto**: uma cor só (bordado, carimbo, sobre foto).
- **carga-vertical-escuro / claro**: espaços quadrados ou altos.
- **carga-simbolo-azul / branco / preto**: avatar, favicon, marca-d'água.
- **carga-palavra-gelo / noite**: só a palavra, quando o símbolo já aparece perto.
- **carga-icone-app / carga-icone-azul**: ícone 512 × 512 com cantos de app.

Área de proteção: a altura da anilha maior. Mínimo: 96 px de largura (horizontal), 16 px (símbolo).
